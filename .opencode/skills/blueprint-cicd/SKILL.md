# Blueprint CI/CD Skill

When modifying CI/CD:

1. Validate the build.
2. Run automated tests.
3. Run quality/security checks appropriate to the project.
4. Produce a versioned deployable artifact.
5. Promote the same artifact between environments where practical.
6. Keep secrets outside source control.
7. Make deployment and rollback repeatable.
8. Add smoke/health verification after deployment where applicable.
