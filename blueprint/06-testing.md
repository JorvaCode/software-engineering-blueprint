# 06 — Testing

Testing is layered according to risk.

## Typical levels
- Unit tests
- Integration tests
- Contract/API tests
- End-to-end tests
- Performance tests when required
- Security tests when required

## Principles
- Tests should verify behaviour.
- Critical acceptance criteria must have automated verification where practical.
- Tests should be deterministic and maintainable.

## Quality gate
Required automated tests pass and known critical risks are covered.
