# Definition of Done

A change is considered done when applicable criteria are satisfied:

- [ ] Requirement and acceptance criteria are clear.
- [ ] Every acceptance criterion states a verification method and names the test or
      check that satisfies it.
- [ ] Design/architecture impact considered.
- [ ] Design quality checked against `standards/code-design.md`; patterns justified or
      explicitly not needed.
- [ ] Vocabulary used as defined in `standards/terms.md`; any new term added there.
- [ ] Normative text written with deliberate modality, per `standards/normative-language.md`.
- [ ] Any quality gate introduced or changed names its artifact, its criterion and its
      evidence, per `standards/normative-language.md`.
- [ ] Any information item introduced or changed states its content, per
      `standards/information-items.md`.
- [ ] Implementation complete.
- [ ] Automated tests added/updated.
- [ ] Required quality checks pass.
- [ ] Security implications checked.
- [ ] Documentation updated where needed.
- [ ] Code review completed.
- [ ] CI passes.
- [ ] Deployable artifact produced where applicable.
- [ ] Deployment/rollback considerations addressed.
- [ ] Observability requirements addressed.
